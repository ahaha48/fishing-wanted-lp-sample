# 釣具買取ウオンテッド — LP制作見本

東京23区の出張買取を軸にした、写真入りランディングページのデザイン見本です。

**実際の営業サイトではありません。LINE査定の申込み、Instagramへの移動、個人情報の入力・送信は受け付けていません。**

## 内容

- PC・タブレット・スマートフォンに対応した1ページ構成
- スマホ下部に追従するLINEボタン
- 開閉できるFAQとモバイルメニュー
- 見本用の案内ダイアログ
- 仮写真3点（人物・釣具・査定風景）

## 仮画像と文章について

文章・実装・仮写真に生成AIを使用しています。写真の人物は架空の人物であり、実際の代表・スタッフではありません。Instagram欄も写真の配置例で、実際の投稿ではありません。

架空の買取実績・口コミ・査定価格は掲載していません。「約1,800億円」は依頼資料にある試算値の表示例で、「※当社試算」を併記しています。本番利用時には試算資料・掲載条件の確認が必要です。

制作条件に合わせ、実際の人物写真・ロゴ・確定原稿への差し替えが必要です。この見本を生成AI不使用の制作物として扱わないでください。

## ファイル

- `index.html`: ページ本体
- `styles.css`: レスポンシブなスタイル
- `app.js`: メニュー・案内ダイアログの動作
- `assets/`: AIで作成した仮写真

外部ライブラリやビルド処理は不要です。GitHub Pagesは`main`ブランチのルートから配信します。

ローカル表示例:

```sh
python3 -m http.server 8000
```

`app.js`の`siteSettings`にある外部アカウントURLは空欄です。公開見本では、そのまま案内ダイアログを表示します。
